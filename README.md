# Portfólio — Guilherme Miranda

Portfólio pessoal de Guilherme Miranda, Designer Gráfico.

O projeto foi construído com React, TypeScript, Vinext, GSAP e Lenis. Inclui:

- apresentação animada;
- galeria infinita de projetos com arraste, inércia e snap;
- pôsteres em escala de cinza com cor no hover;
- páginas individuais de projeto;
- layout responsivo para computador e celular.

## Requisitos

- Node.js 22.13 ou superior
- npm

## Abrir no computador

```bash
npm install
npm run dev
```

Depois, abra:

```text
http://localhost:3000
```

## Verificar o projeto

```bash
npm run build
npm test
```

## Onde editar

- Conteúdo e estrutura: `app/`
- Imagens, vídeos e fontes: `public/`
- Estilos gerais: `app/globals.css`
- Lista e informações dos projetos: `app/project-data.ts`

## Observação sobre o GitHub

O repositório guarda o código completo, mas enviar os arquivos ao GitHub não publica o site automaticamente. Para deixar o portfólio acessível por um endereço público, ainda é necessário conectá-lo a um serviço de hospedagem compatível.
